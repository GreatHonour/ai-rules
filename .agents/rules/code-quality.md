# 代码质量规范

## 常犯错误

> 以下为 AI 屡次犯错的记录，编写代码时务必自查。

1. **及时清理死代码**：未使用的 export 常量、空 `<style scoped>`、未赋值的 `ref` 都要及时删除。
2. **禁止重复代码**：同一模块内已有工具函数时，必须复用而非手写同款逻辑（如已有 `isStr` 则禁止再写 `typeof value === 'string'`）。
3. **直白实现，不要过度封装**：使用简洁的代码实现逻辑，不要绕弯子，直白一点。
4. **解构兜底一步到位**：解构外部数据时，空值兜底和类型守卫一次性写全，不要拆分补丁。
