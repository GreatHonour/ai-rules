# Flow v3

根据当前目标选择一个且仅一个子 Skill：

- 交付范围、仓库、分支、平台和目标阶段登记：`flow-intake/SKILL.md`
- 需求与业务规则澄清：`flow-brainstorm/SKILL.md`
- 根据已确认决策生成设计与任务：`flow-plans/SKILL.md`
- 设计与任务追踪审查（可选）：`flow-plan-review/SKILL.md`
- 按任务实现并执行 TDD：`flow-implement/SKILL.md`
- 审查实现是否偏离设计和任务：`flow-review/SKILL.md`
- 生成轻量验收清单：`flow-test-plan/SKILL.md`
- 执行已授权的环境部署：`flow-deploy/SKILL.md`
- 按验收清单和平台适配器验证：`flow-verify/SKILL.md`
- 按目标阶段归档交付：`flow-archive/SKILL.md`
- 可复现缺陷与小型变更：`flow-bugfix/SKILL.md`

共享状态、验收清单格式、部署适配器和授权边界见 `_shared/references/`。
