# 部署

读取 `delivery.json`、`authorization.md`、`adapters.md` 和项目部署说明。部署是独立动作，不内置“测试环境”或“生产环境”的固定流程；根据交付登记选择 Jenkins、CI/CD 或项目适配器，并接收目标环境作为参数。

触发前确认仓库、分支/提交、部署目标和副作用授权。若登记了数据库迁移、配置变更或回滚，必须按已确认顺序执行并记录结果；失败时保留失败事实，不把回滚成功改写成初始部署成功。

输出同一日期目录的 `deploy-report.md` 和 `evidence/` 下的机器/流水线事实：仓库、分支、提交、目标、结果、时间、锚点、迁移/配置/回滚结果。无授权、适配器不可用或事实不可复核时标记 `blocked`。完成后进入 `flow-v3-verify`。
