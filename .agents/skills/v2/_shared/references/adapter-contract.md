# 项目适配器契约

v2 Skill 不内置供应商命令、凭证、固定地址、设备标识或部署配置；项目适配器负责具体连接和执行。

适配器输入应包含交付 ID、目标环境、操作意图、允许副作用和证据目的；输出应包含：

- `status`：`passed`/`failed`/`blocked`/`inconclusive`；
- `facts`：仓库、分支、提交、构建、环境和时间；
- `command`：argv 数组，不保存秘密；
- `evidence`：仓库相对路径及脱敏观察；
- `sideEffects`：实际发生或计划发生的副作用；
- `anchor`：可复核的流水线、部署或运行锚点。

适配器不得隐式扩大范围或权限；外部写入仍需用户对当前目标明确授权。
