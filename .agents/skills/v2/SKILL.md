# Flow v2

选择一个且仅一个与当前目标匹配的子 Skill：

- 新交付或范围不清：`flow-v2-intake/SKILL.md`
- 决策已确认，需要设计和任务：`flow-v2-plan/SKILL.md`
- 按计划写代码：`flow-v2-implement/SKILL.md`
- 审查已完成改动：`flow-v2-review/SKILL.md`
- 建立验收证据：`flow-v2-verify/SKILL.md`
- 诊断并修复缺陷：`flow-v2-repair/SKILL.md`
- 证明生产发布：`flow-v2-release/SKILL.md`
- 交接、知识与归档：`flow-v2-close/SKILL.md`

共享门禁见 `_shared/references/`。阶段只由事实推导；默认只读，外部写入需明确授权。
