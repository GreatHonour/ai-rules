# 收口

读取 [状态模型](../_shared/references/state-model.md)、[证据契约](../_shared/references/evidence-contract.md) 与 [收口模板](../_shared/assets/close-template.md)。确认任务、审查、验收和发布事实均已链接；只归档已经证实的范围、结果、限制和遗留项。

生成可发送但不自动发送的交接稿；知识记录遵循“症状→影响→已验证原因→无效尝试→解决→证据→规则”，删除凭证、个人信息、私有 URL、绝对路径和临时日志。归档关闭过程，不改变 `verified`/`released` 的事实含义。

清理仅限本次迭代的过程文件；提交前检查变更归属，禁止把用户或其他迭代的修改带入提交。
