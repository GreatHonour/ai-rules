# 审查

前置条件：存在本次可归属的代码差异，且实现任务已完成或明确标记阻塞。读取 [证据契约](../_shared/references/evidence-contract.md) 和项目适用规则。

以任务开始前提交为基线，核对行为、边界、异常、安全、性能、兼容性和测试覆盖；只报告能定位到文件/行或验证结果的问题。使用 [审查模板](../_shared/assets/review-template.md) 输出问题、影响、依据、建议和状态。

审查结果先交给用户确认；确认前不修改代码。问题修复后重新验证受影响范围。审查通过不等于验收通过。
