# 计划

前置条件：目标、范围、关键规则、边界和非目标已经确认，且存在 `delivery.json`。读取 [状态模型](../_shared/references/state-model.md) 与 [证据契约](../_shared/references/evidence-contract.md)。

使用 [计划模板](../_shared/assets/plan-template.md) 生成设计与任务；每个任务必须有明确结果、依赖和验证方式，任务初始为未完成。把每条需求映射到至少一个用例，并标注所需证据。发现会改变业务契约或范围的缺口时停止，返回需求澄清，不擅自定案。

实施前从原始决策重新建立“决策→设计→任务→用例”追踪，并用具体场景反证状态、权限、并发、生命周期和外部依赖；阻塞断链清零后才可进入实施。

输出计划路径、阻塞决策和覆盖缺口。计划完成只表示 `specified` 的候选条件，不代表代码、验收或发布完成。
