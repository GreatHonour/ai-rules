# 样式

| # | 规则 |
|---|------|
| ST-1 | 小程序如果使用 `Unocss` 或 `Tailwindcss` 禁止使用 `\[\]` |
| ST-2 | `UnoCSS` 或 `Tailwindcss` 原子类优先，禁止随手写自定义 class，除非确实没有对应原子类 |
| ST-3 | 禁止在 `WXML` 里写静态行内 `style`；允许计算后绑定的动态 `style` |
| ST-4 | 自定义 `CSS` 变量必须在 `:root` 级别定义，来源可追溯 |
| ST-5 | 小程序不支持真正的媒体查询，`@media` 禁止用于响应式布局；改用系统信息 `API` 或条件渲染 |
