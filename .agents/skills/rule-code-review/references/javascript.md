# JavaScript 通用

| # | 规则 |
|---|------|
| JS-1 | 函数保持单一职责，单个函数尽量控制在 35 行内；禁止过度拆分，逻辑内聚的代码块不要强行抽函数 |
| JS-2 | 优先使用 `const`，需要重新赋值时使用 `let`，禁止使用 `var` |
| JS-3 | 魔法数字、魔法字符串必须提取为命名常量 |
| JS-4 | `async/await` 必须处理异常；入口层、IO、网络、外部命令必须使用 `try/catch` |
| JS-5 | 顶层业务函数优先使用 `function`，减少 `const fn = () => {}`；回调函数可以使用箭头函数 |
| JS-6 | 函数形参超过 2 个时，改为对象参数，并为对象字段提供清晰命名 |
| JS-7 | `setInterval` / `setTimeout` 必须保存句柄，并在合适时机清理，避免内存泄漏 |
| JS-8 | 循环或高频调用路径禁止重复创建固定对象、数组、正则或映射表；可上提为常量 |
| JS-9 | 禁止隐式类型转换；比较使用 `===` / `!==`，输入数据显式转换 |
| JS-10 | 条件分支超过 3 层时优先提前返回，避免深层嵌套 |
| JS-11 | `catch` 不能空处理，必须记录上下文、返回明确失败结果或重新抛出 |
| JS-12 | 简单枚举映射优先使用对象 / `Map`；复杂流程可以使用 `switch`，但必须清晰 `return` / `break`，禁止隐式 fallthrough |
