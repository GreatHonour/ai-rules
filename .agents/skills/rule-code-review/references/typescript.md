# TypeScript

| # | 规则 |
|---|------|
| TS-1 | 禁止使用 `any`；未知数据使用 `unknown`，通过类型守卫收窄后再使用 |
| TS-2 | 禁止滥用 `as` 类型断言；禁止 `as unknown as` 双重断言；只有第三方边界、JSON 解析、DOM 查询等无法推导场景允许使用 |
| TS-3 | 禁止使用非空断言 `!`；优先用显式判空、`?.`、`??` 处理 |
| TS-4 | 函数参数和返回值必须显式声明类型；导出函数、异步函数必须写返回类型 |
| TS-5 | 对象参数必须定义 interface / type，禁止在复杂函数签名里堆内联对象类型 |
| TS-6 | 接口返回数据必须定义 DTO 类型，禁止直接使用裸对象或 `Record<string, unknown>` 代替业务类型 |
| TS-7 | 字面量状态优先使用联合类型，避免用多个 boolean 表达同一状态 |
| TS-8 | 字典映射使用 `Record<K, V>` 或 `Map<K, V>`，禁止无约束索引访问 |
| TS-9 | 可空值必须体现在类型中，例如 `string \| null`；禁止用空字符串、`0`、`false` 偷偷表达缺省状态 |
| TS-10 | 泛型必须有明确约束，禁止无约束泛型滥用，例如 `<T>(value: T) => T` 这种无业务含义封装 |
| TS-11 | 类型定义不要过度抽象；只使用一次的简单类型就近定义，复用 2 次以上再抽公共类型 |
| TS-12 | 禁止为了绕过类型错误而改宽类型；应该修正数据结构或补类型守卫 |
| TS-13 | ~~类型导入必须用 `import type`~~ 【小程序不支持，禁用】 |
