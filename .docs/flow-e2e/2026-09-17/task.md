# flow-e2e 任务状态文件

#### [x] T1: 初始化本轮任务 JSON

depends: 无

- task.md 或 xx-fix.md 加任务数组 → 在来源目录生成规定名称的 JSON。
- 文件已存在、任务为空或 ID 重复 → 拒绝写入，保留已有内容。

#### [x] T2: 按 ID 读取和更新任务

depends: T1

- 读取 task_id → 返回对应任务、验收内容和未通过的 depends 依赖。
- 更新状态、说明和证据 → 只改变指定任务；未知 ID、非法状态、空失败说明或无效证据地址拒绝写入。

#### [x] T3: 校验完成情况并生成失败报告

depends: T2

- pending → 返回未完成任务，不生成最终报告。
- 没有 pending → 汇总同目录全部任务文件，将失败和阻塞任务详情写入 e2e-report.md。
- 全部通过 → 报告明确无失败；CLI 正确区分成功、失败和未完成退出码。

#### [x] T4: 接入精简技能流程

depends: T3

- 模板含任务 ID、名称、验收内容、depends、状态、说明和 evidence；技能说明命名、生成、按 ID 执行、更新和最终校验入口。
- 工具按 PC/H5、微信开发者工具、移动端和视觉对比的既定映射选择；用户提供的工具均不可用时，建议替代工具并等待确认。
