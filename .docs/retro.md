## 2026-09-10 agentctl

### 代码 文件事务需要显式提交边界

- 依据：代码审查发现备份清理失败可能触发错误回滚；修复后 20 个测试、类型检查和构建通过。
- 原因：把安装新文件、提交状态和清理备份放在同一个异常处理区间，会将提交后的清理错误误判为事务失败。
- 改进：先完成可回滚的写入与状态提交，再将临时文件和备份清理作为 best-effort 收尾；回滚失败时保留备份。

### 安全 Git 参数必须在调用进程前校验

- 依据：审查确认 manifest 中的 URL/ref 可进入 Git 参数；新增恶意 URL/ref 回归测试后完成修复。
- 原因：数组参数可以避免 shell 注入，但不能自动避免被子命令解释为选项。
- 改进：对 URL、ref 和 commit 分别做领域校验，并在 Git 支持的位置使用 `--` 终止选项解析。
